# Восстановление моделей карты

## Причина синих кубов

Дамп `db_export.sql` содержит ссылки на модели, которых нет в репозитории. При проверке найдено 95 уникальных путей моделей объектов карты, из них 93 отсутствовали в `public/models/uploaded`. Кубы — заглушки загрузчика. Ответ 404 на запрос GLB означает, что модель недоступна. Скрытие полосы загрузки по таймеру не подтверждает успешную загрузку.

На публичном демосервере автора `https://miduo100.com` доступны некоторые из этих файлов. Скрипт проверяет доступность каждого требуемого файла скачиванием; наличие всех файлов заранее не гарантируется.

## Восстановление

```bash
cd ~/projects/3d-virtual-world
python3 scripts/restore-world-models.py --dry-run
python3 scripts/restore-world-models.py
```

Скрипт читает секцию `world_objects` SQL-дампа и скачивает отсутствующие модели с путями `/models/uploaded/`. Существующие файлы не перезаписываются. Одновременно скачиваются три файла. GLB проверяется по сигнатуре, версии и заявленной длине; временный файл становится моделью только после проверки. Файлы получают права чтения для процесса приложения. Структура сцены и материалы проверяются уже загрузчиком игры. Внешние зависимости GLTF и OBJ автоматически не восстанавливаются.

Итог — `model-restore-report.json`: скачанные, существующие и неудачные файлы. При ошибках команда возвращает ненулевой код. Её можно повторить: уже скачанные файлы будут пропущены. Скрипт не запускает приложение или Docker, не меняет базу и не скачивает файлы персонажей, анимаций или ресурсы других разделов. Если рабочая база менялась после импорта, дамп может не отражать её новые объекты.

## Перенос в работающий контейнер

В `docker-compose.local.yml` каталог `/app/public/models` находится в отдельном томе. Пересборка образа не обновляет содержимое существующего тома. После скачивания выполните:

```bash
chmod a+r public/models/uploaded/*.glb
docker compose -f docker-compose.local.yml cp public/models/uploaded/. app:/app/public/models/uploaded/
curl -I http://localhost:3002/models/uploaded/model-1788059210785-10086802.glb
```

Для проверяемой модели ожидается HTTP 200. Затем обновите игру через Ctrl+Shift+R. Копирование может перезаписать файлы с совпадающими именами в томе; команда предназначена для этой локальной среды с недостающими моделями. Базу и тома удалять не нужно. Docker daemon и контейнер приложения должны быть запущены.

Если файл недоступен и на сервере автора, запросите у автора архив ресурсов, соответствующий дампу, либо отдельно замените такой объект в редакторе. Отчёт перечисляет эти пути.
