# 3dtalks

Переговорные комнаты в браузере: кабинет пользователя, вход по ссылке,
посадочные места и административный редактор шаблонов помещений.

- [Локальная разработка и запуск](LOCAL_DEVELOPMENT.md)
- [Развёртывание и обновление на сервере](SERVER_DEPLOYMENT.md)

Код основан на [3d-virtual-world](https://github.com/miduo100/3d-virtual-world).
Авторские уведомления и условия использования сохранены в [LICENSE](LICENSE)
и [EULA](EULA.md).
