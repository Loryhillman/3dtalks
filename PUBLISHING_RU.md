# Публикационная копия 3dtalks

Этот репозиторий содержит код и новую историю изменений. Исходный проект:
https://github.com/miduo100/3d-virtual-world . Авторские уведомления, LICENSE
и EULA сохранены; условия исходного проекта продолжают действовать.

## Что переносится отдельно

В Git не включены рабочий `.env`, дамп `db_export.sql`, зависимости
`node_modules` и загруженные модели/медиа. Комната, мебель и порталы хранятся
в работающей PostgreSQL, поэтому клонирование репозитория их не переносит.

Для переноса текущего мира нужны актуальная резервная копия PostgreSQL,
файлы из используемых Docker volumes и отдельно настроенные секреты сервера.
Старый `db_export.sql` не содержит изменения, сделанные после его импорта.

## Локальный Compose

`docker-compose.local.yml` использует `./db_export.sql` при инициализации новой
базы. Перед запуском из свежего клона этот файл нужно предоставить отдельно.
Локальная конфигурация публикует порт только на 127.0.0.1 и использует
демонстрационный пароль; для внешнего сервера нужна отдельная настройка.

Примеры `.env.*.example` предназначены для заполнения. Для нового сервера
задайте собственные пароли и случайные секреты JWT. Рабочий `.env` не коммитьте.

## Рабочие каталоги

Исходный рабочий каталог: `~/projects/3d-virtual-world`.
Публикационная копия: `~/projects/3dtalks-publish`.
Изменения между ними автоматически не синхронизируются. После публикации
выберите один основной каталог для дальнейшей разработки, чтобы версии не разошлись.
