# Локальный просмотр кандидата

Подготовленные модели теперь включены в Git. Для выбора мужского персонажа
азиатской внешности или женского варианта (с записью и воспроизведением голоса):

```bash
node scripts/avatar-lipsync-lab.js public/assets/avatars/meeting-human-v1/male-asian.glb 4187 --meeting-candidates
```

Открыть http://localhost:4187/ и поле «Модель». Смена модели перезагружает страницу
и сбрасывает запись. Поддерживается только подготовленная форма А; остальные
ручные формы отключены. Размер 3,2/3,7 МиБ, скелет/рот/посадка/шесть экземпляров
проверены. Это пока кандидаты, а не выбранный в аккаунте стандарт.
Проверка без Blender: `node scripts/test-meeting-avatar-assets-browser.js`.
Источники, сборка и границы — ../../docs/research/avatar-lipsync/MEETING_HUMAN_V1.md.
Ниже сохранены инструкции для прежнего тяжёлого технического образца.

Отдельный инструмент исследования: использует Three.js, GLTFLoader,
UserAvatarRenderer и RoomSeatAvatar проекта, без API и аккаунтов.
Сервер доступен только через 127.0.0.1.

## Запуск из корня репозитория в WSL

При наличии уже установленных зависимостей проекта и исходника:

```bash
python3 scripts/prepare-avatar-lab-model.py /tmp/3dtalks-avatar-research/mpfb.glb /tmp/3dtalks-avatar-research/mpfb-lab.glb
node scripts/avatar-lipsync-lab.js /tmp/3dtalks-avatar-research/mpfb-lab.glb 4187
```

Открыть http://localhost:4187/. Остановка — Ctrl+C. Выходной каталог должен
существовать. Если mpfb-lab.glb уже подготовлен, первую команду повторять
не нужно: повторный вывод требует нового пути.

Сохраняются viseme_*, jawOpen и eyeBlinkLeft/Right. Остальные выражения
удаляются только из экспериментальной копии. Геометрия тела, текстуры,
skinning и скелет сохраняются; используемые sparse accessors переводятся
в плотные, неиспользуемые данные исключаются. Штатный validator не менялся.
Модель всё ещё тяжёлая: 29,0 МиБ и 83 686 треугольников. Она пока не готова
для шести мобильных участников.

## Управление

- «Персонаж целиком»: тело и пропорции.
- «Лицо крупно»: формы А, О, М/П/Б и jawOpen, сила 0–100%.
- «Посадка»: настоящий RoomSeatAvatar с исходным скелетом.
- «Вернуть нейтральное лицо»: обнуление управляемых форм.

Ракурсы фиксированы для сравнения. «Ручные формы рта» раскрывают ползунок.
В разделе «Рот по звуку» нажать «Записать с микрофона», разрешить доступ,
произнести фразу, нажать «Завершить запись», затем «Воспроизвести».
Микрофон запрашивается только по кнопке; требуется localhost или HTTPS.
Запись ограничена 30 секундами и 12 МиБ, хранится в памяти браузера и никуда
не отправляется. Следующая запись заменяет предыдущую; перезагрузка её удаляет.
После завершения записи микрофон отключается. Остановка, скрытие вкладки,
отмена запроса разрешения и закрытие страницы также освобождают захват;
незавершённая запись при отмене отбрасывается. Во время записи звук не выводится:
рот анимируется при последующем воспроизведении. Это проверка энергии, не фонем.

В дополнительном разделе «Аудиофайл и пример» можно выбрать локальный WAV
PCM 16-bit (моно/стерео, 8–48 кГц, до 60 секунд и 12 МиБ), затем нажать
«Воспроизвести». Файл читается непосредственно браузером без HTTP-загрузки.
На входе проверяется несжатый PCM-WAV до создания AudioBuffer.

Необязательный четвёртый аргумент сервера — путь к собственному локальному
примеру WAV. Тогда появится кнопка «Загрузить пример речи», а затем нужно
нажать «Воспроизвести». Пример не стартует автоматически:

```bash
node scripts/avatar-lipsync-lab.js /tmp/3dtalks-avatar-research/mpfb-lab.glb 4187 /tmp/3dtalks-avatar-research/speech-demo.wav
```

В текущем сеансе пример — локально синтезированная русская фраза с паузами.
Этот WAV не включён в Git и не обязателен для работы инструмента.
Остановка, окончание записи и скрытие вкладки закрывают рот; закрытие страницы
освобождает AudioContext. На следующем Play запись начинается с начала.
Пауза/seek/зацикливание пока не реализованы.

Анимация использует сглаженную энергию по 20-мс окнам, не распознаёт фонемы.
Рот управляется формой viseme_aa и часами того же AudioContext, который
воспроизводит запись. Нет отдельного сервиса, транскрипции или передачи мимики.

## Повторяемая проверка

```bash
node scripts/test-avatar-lab-browser.js /tmp/3dtalks-avatar-research/mpfb-lab.glb /tmp/3dtalks-avatar-research/mpfb.glb
node scripts/test-avatar-lab-audio.js
```

Требует Chromium/Playwright. Проверяет старый validator, совпадение координат
тела и сохранённых morph-данных с оригиналом, формы рта, нейтральное лицо,
реальную посадку, мобильную ширину и остановку. Проверено отсутствие запросов
к API/внешним сервисам. Сравнены 53 116 вершин и 1 910 568 компонентов morph
с точностью 1e-7. Теперь проверено также управление настоящими morph-весами
при Web Audio воспроизведении и нейтральный reset после него.
Отдельный audio-тест проверяет тишину, стерео, stop/late resume/read и закрытие,
настоящие MediaRecorder/getUserMedia с синтетическим устройством Chromium,
воспроизведение записи, отказ/повтор, позднее разрешение, автоматический лимит,
скрытие вкладки и освобождение всех дорожек. Полный UI-тест также записывает
синтетический микрофон и проверяет morph-веса модели при воспроизведении.
Фонетическая точность, физические устройства и производительность шести
участников остаются вне этой проверки.

Профили и рендеры: ../../docs/research/avatar-lipsync/.
