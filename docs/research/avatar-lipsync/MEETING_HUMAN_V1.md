# Подготовленные человеческие аватары v1

21 октября 2026. Это комплект кандидатов на стандартный аватар. В кабинете,
WebSocket-конфигах и редакторе мест прежний default ещё не заменён.

| Модель | Размер | Треугольники |
|---|---:|---:|
| Мужчина, азиатская внешность | 3 360 528 байт / 3,2 МиБ | 35 580 |
| Женский персонаж | 3 868 412 байт / 3,7 МиБ | 37 588 |

Канонический каталог: `public/assets/avatars/meeting-human-v1/`. GLB находятся
в Git вместе с recipe.json, SHA-256, метаданными скелета и лицензиями компонентов.
Существующий валидатор принимает оба без изменений; sparse accessors и внешних
текстур нет. Скелет Mixamo, единственная форма лица — viseme_aa с согласованными
зубами и языком. Это открывание рта по звуку, не полноценная артикуляция/мимика.

Внешность мужчины создана параметрами MPFB, а не переименованием прежней модели.
Короткие волосы, нейтральное лицо, рубашка, джинсы и обувь. Женский вариант —
другая геометрия тела/головы и причёска; та же рубашка подогнана MPFB к телу.
Окончательное соответствие стилю продукта остаётся предметом просмотра пользователем.

## Права и источники

Использованы только core/system assets MakeHuman и Visemes 02 (CC0).
Автор набора визем — Mika Suominen. В catalog.json есть лицензии каждого

MPFB GPL используется только как отдельный инструмент подготовки; его исходники
не поставляются с приложением. Полная запись — LICENSE.md внутри комплекта.

## Повторение подготовки

Нужны отдельный Blender 4.5.3 LTS и исходники MPFB 2.0.18 на commit
`b1a2dc98776da9d1eea751b159d42cf61778fe2e`. Рецепт проверяет версию Blender,
commit и отсутствие изменений отслеживаемых исходников MPFB. Установка
на компьютер пользователя и запуск Blender UI не требуются: использовалась
отдельная распакованная копия в /tmp внутри WSL.

Blender: `https://download.blender.org/release/Blender4.5/blender-4.5.3-linux-x64.tar.xz`,
SHA-256 `975c58fcb244273838534bba771e64ad87739216b0f9b39a888531a49a72d845`
(сверен с официальным blender-4.5.3.sha256).
Два архива assets — URL/SHA-256 в catalog.json. Проверить контрольные суммы,
распаковать оба в `ISOLATED_MPFB_HOME/data` (имя каталога по выбору).
Работать с отдельным новым каталогом; не использовать пользовательский Blender profile.

```bash
/path/to/blender --background --factory-startup --python-exit-code 1 \
  --python scripts/build-meeting-avatar-assets.py -- \
  /path/to/mpfb2/src /path/to/isolated-mpfb-home /path/to/new-output-directory
```

Скрипт не скачивает зависимости, не переписывает существующий результат и
не выполняется сервером. Он создаёт варианты, применяет одежду/скелет, печёт
геометрию, переносит открывание рта, убирает скрытые поверхности и subdivision,
уменьшает текстуры до 1024px, экспортирует плотные accessors. Кожа/одежда
непрозрачные, волосы/брови/ресницы используют alpha mask. При первом визуальном
просмотре был найден дефект сквозного лица из-за BLEND; в комплект включена
исправленная версия. Сгенерированные неудачные версии в Git не добавлялись.

Повторная сборка в отдельный каталог дала те же SHA-256 обоих GLB.
Выпущенные файлы закреплены этими суммами. При смене инструментов или рецепта
новый результат необходимо проверить и выпускать отдельно, а не подменять v1.

## Проверки

```bash
node scripts/test-meeting-avatar-assets-browser.js
node scripts/test-avatar-lab-audio.js
node scripts/test-meeting-mouth-animation.js
node scripts/test-meeting-mouth-browser.js
```

Первый тест не требует скачанного MPFB/Blender. Он проверяет комплект в Git,
штатный валидатор, отсутствие sparse/BLEND/внешних изображений, настоящий
UserAvatarRenderer/RoomSeatAvatar в Chromium: анфас, открытый рот, посадка,
запись синтетического микрофона и воспроизведение, ширина 390px. Также шесть
отдельно загруженных GLB, независимость morph-весов и освобождение GPU.
Скриншоты лица/посадки/шести персонажей просмотрены.

Наблюдение шести чередующихся экземпляров: 219 504 треугольника, 54 draw calls,
54 геометрии и 103 текстуры в счётчике Three.js. После удаления — 0 геометрий
и 1 текстура: это прогретая общая DFG_LUT рендерера Three.js r185, не ресурс
аватара. Состояние совпало с прогретой базовой сценой. Рендерер закрывается.
Измерение выполнено в headless Chromium/SwiftShader на отдельной сцене;
оно не доказывает FPS на телефоне или производительность полной комнаты.

Изначальный ориентир ~25k треугольников не достигнут: сохранена геометрия лица,
кистей и зубов, пакет имеет 36–38k. Размер уменьшился примерно в 8–9 раз
относительно прежнего 29-МиБ образца. До объявления мобильной готовности
нужно измерение полной стандартной комнаты на реальном устройстве.

Физический микрофон пользователя и разговор двух настоящих пользователей
этим тестом не заменяются. API аккаунта, сохранённые аватары и сервер/VPS
в ходе подготовки комплекта не изменялись.

## Локальный просмотр

```bash
node scripts/avatar-lipsync-lab.js \
  public/assets/avatars/meeting-human-v1/male-asian.glb 4187 --meeting-candidates
```

Открыть http://localhost:4187/. Поле «Модель» переключает кандидата с
перезагрузкой страницы и очисткой предыдущей записи/ресурсов.
Работают крупное лицо, посадка, ручная форма А и запись микрофона.
У этих моделей не заявлены неподготовленные О/М/челюсть: соответствующие
ручные варианты отключены. Исходный технический стенд по-прежнему можно
запустить прежней командой без `--meeting-candidates`.

Следующий этап — серверный allowlist-каталог, выбор в аккаунте и единое
разрешение default в кабинете, WS, /play и редакторе мест. Пользовательские
модели/головы не перезаписывать. Политика — MEETING_AVATAR_INTEGRATION.md.
