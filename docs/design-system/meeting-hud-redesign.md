# Панели встречи, чат и микрофон — результат и QA

Дата: 2026-10-20. Ветка: codex/room-presentations. Этап согласован отдельно
после окон материалов/показа. Изменены meeting.css, meetingUI/VoiceControl,
UI-участки nearbyChat/roomSeating/roomPresentation/roomScreenPreview/meetingMain,
переводы и cache keys в HTML. Добавлена SVG-иконка микрофона в существующий набор.

## Результат

Светлые панели используют app-controls/tokens без App Shell и фона страницы.
Название комнаты, места, выход, язык и действия экрана сохранены.
Чат получил раскрываемую историю существующих сообщений, пустое состояние,
поле 16 px и доступную кнопку отправки. Лимит 200 символов сохранён.
Микрофон обозначает удержание, запись и недоступность; выключенное входящее
воспроизведение показывается отдельно. Команды WebSocket/посадки не менялись.

На узком экране действия экрана временно скрыты при открытом выборе мест,
возвращаются при закрытии. Низкий landscape размещает picker и toolbar рядом.
Видимая область измеряется через visualViewport; размеры footer учитываются
при ограничении верхних панелей. Допуск/переподключение блокируют панели через
inert, сохраняют управление клавиатурой и возврат фокуса. Завершение встречи
отключает UI observers/listeners, освобождает удержание микрофона и очищает чат.

## Design QA Report

- Visual QA: PASS для просмотренных Chromium-скриншотов desktop/mobile,
  включая настоящую встроенную комнату с офисом, мебелью и аватарами.
  Снимки создаёт MEETING_UI_SCREENSHOTS=1 в startup-тесте в /tmp.
- Functional QA: PASS — существующая посадка, PTT, история без HTML-интерпретации,
  offline draft, reconnect/focus/inert, переключение языка и stop cleanup.
- Responsive QA: PASS — 1366×768, 1920×1080, 1280×800, 768×1024, 430×932,
  375×812, 390×844, 320×568, 568×320. Проверены границы и непересечение панелей;
  при раскрытой истории — также mobile/landscape.
- Accessibility QA: PASS для проверенных Enter/Space/Tab/Escape, фокуса,
  aria-label/log/live и текстового контраста >=4.5 на фактических CSS-парах.
  NOT RUN: axe, screen reader, полноценный 200% zoom, реальные touch-устройства
  и экранная клавиатура. Соответствие WCAG целиком не заявляется.
- Localization: PASS — ru-RU/en-US/zh-CN, включая динамические voice labels
  после общего translatePage. Пользовательские имена не переводятся.
- States: PASS — empty/history, запись/недоступность/выключенный звук,
  disconnected admission/recovery, offline send с сохранением текста.
- Build: отдельная сборка не требуется для изменённых статических JS/CSS.
  Проверены синтаксис JS/JSON и git diff --check.
- Сервер, API, авторизация, квоты, Three.js, модели и камера не изменены.
  Нет новой серверной истории сообщений или гарантии доставки offline-команд.

Docker, VPS, push и развёртывание на этом этапе не выполнялись.

## Ручная приёмка

1. Войти в комнату на desktop и телефоне; открыть места, выбрать место, закрыть.
   Проверить доступность чата, действий экрана и выхода в portrait/landscape.
2. Раскрыть сообщения, отправить текст между двумя аккаунтами; сменить язык.
   Проверить ввод с экранной клавиатурой, длинный текст и масштаб браузера 200%.
3. Удержать микрофон мышью/касанием/Space, отпустить и переключить вкладку.
   Проверить отказ доступа к микрофону, входящий звук и восстановление соединения.
4. Открыть материалы/показ/увеличенный экран; проверить Escape/Tab, закрыть встречу.

После коммита остановиться для пользовательской проверки. Редактор и дальнейшие
продуктовые изменения требуют отдельной задачи.
